# Meowdoku

## Run locally

- Java: OpenJDK 17+
- OS: Windows PowerShell / macOS / Linux shell with Java 17

Build all classes:

```powershell
javac -encoding UTF-8 -d . *.java
```

Start web server:

```powershell
java WebMain
```

Then open:

```text
http://localhost:8080
```

For CLI play (unchanged):

```powershell
java Main
```
